# knowledge

В данной программе используются следующие Assembler регистры и операции:

| Запись               | Тип                   | Описание                                                                                 |
| -------------------- | --------------------- | ---------------------------------------------------------------------------------------- |
| `ST(0)`              | Регистр               | Верхний элемент стека x87 FPU. Основной регистр для операций с `double`.                 |
| `ST(1)`              | Регистр               | Второй элемент стека x87 FPU.                                                            |
| `fld`                | Команда               | Загружает значение `double` в вершину стека x87.                                         |
| `fstp`               | Команда               | Сохраняет значение из вершины стека в переменную и удаляет его из стека.                 |
| `fmul`               | Команда               | Умножает значения с плавающей точкой.                                                    |
| `fadd`               | Команда               | Складывает значения с плавающей точкой.                                                  |
| `fsub`               | Команда               | Вычитает значение с плавающей точкой.                                                    |
| `fdiv`               | Команда               | Делит значения с плавающей точкой.                                                       |
| `faddp`              | Команда               | Складывает `ST(0)` и `ST(1)`, записывает результат в `ST(1)` и удаляет `ST(0)`.          |
| `fsubp`              | Команда               | Вычитает `ST(0)` из `ST(1)`, записывает результат в `ST(1)` и удаляет `ST(0)`.           |
| `fdivp`              | Команда               | Делит `ST(1)` на `ST(0)`, записывает результат в `ST(1)` и удаляет `ST(0)`.              |
| `fmul st(0), st(0)`  | Команда               | Умножает `ST(0)` само на себя, то есть вычисляет квадрат значения.                       |
| `x87 FPU`            | Устройство процессора | Модуль процессора для операций с вещественными числами. Использует стек `ST(0)`–`ST(7)`. |
| `ST(0)` → `ST(1)`    | Стек                  | При `fld` текущие элементы стека сдвигаются вниз, а новое значение становится `ST(0)`.   |
| `faddp st(1), st(0)` | Операция со стеком    | `ST(1) = ST(1) + ST(0)`, затем `ST(0)` удаляется.                                        |
| `fsubp st(1), st(0)` | Операция со стеком    | `ST(1) = ST(1) - ST(0)`, затем `ST(0)` удаляется.                                        |
| `fdivp st(1), st(0)` | Операция со стеком    | `ST(1) = ST(1) / ST(0)`, затем `ST(0)` удаляется.                                        |
