# Самостоятельная работа №04

## Задача 1

Вычислить значение y:

$$
y = \begin{cases}
   a + bx &\text{если } x > 0 \\
   x^2    &\text{если } x < 0 \\
   1      &\text{если } x = 0
\end{cases}
$$

## Задача 2

Ввести целое число. Если оно является положительным, то прибавить к нему 1; в противном случае не изменять его. Вывести полученное число.

## Задача 4

## Задача 5
