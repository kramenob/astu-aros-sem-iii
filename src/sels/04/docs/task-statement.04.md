# Самостоятельная работа №04

**Цель:** Изучение работы логических команд.

- [x] Реализовать вычисление указанных формул в виде ассемблерных вставок в текст программы на С++.
- [x] Вычисления осуществлять в целых числах **типа integer**.

- [x] Объявление необходимых переменных, ввод данных и вывод результатов на экран реализовать на С++.
- [x] Для проверки правильности вычисления ассемблерной вставки реализовать вычисления на С++ с выводом результатов на экран.

- [x] Программа должна выводить на экран фамилию разработчика, номер лабораторной работы и номер варианта.

## Задача 1

- [x] Вычислить значение y:

$$
y = \begin{cases}
   a + bx &\text{если } x > 0 \\
   x^2    &\text{если } x < 0 \\
   1      &\text{если } x = 0
\end{cases}
$$

## Задача 5
