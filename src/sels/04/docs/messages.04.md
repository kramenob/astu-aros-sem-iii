# intro

**Цель:** Изучение работы логических команд.

Реализовать вычисление указанных формул в виде ассемблерных вставок в текст программы на С++.
Вычисления осуществлять в целых числах **типа integer**.

Объявление необходимых переменных, ввод данных и вывод результатов на экран реализовать на С++.
Для проверки правильности вычисления ассемблерной вставки реализовать вычисления на С++ с выводом результатов на экран.

Программа должна выводить на экран фамилию разработчика, номер лабораторной работы и номер варианта.

# taskI

Задача 1

Вычислить значение y:

$$
y = \begin{cases}
   a + bx &\text{если } x > 0 \\
   x^2    &\text{если } x < 0 \\
   1      &\text{если } x = 0
\end{cases}
$$
