# intro

**Цель:** Изучение работы команд умножения и деления целых чисел.

- [ ] Реализовать вычисление указанных формул в виде ассемблерных вставок в текст программы на С++.
- [ ] Вычисления осуществлять в целых числах типа **int** (использовать регистры процессора).
- [ ] Объявление необходимых переменных, ввод данных и вывод результатов на экран реализовать на С++.
- [ ] Для проверки правильности вычисления ассемблерной вставки реализовать вычисления на С++ с выводом результатов на экран.
- [ ] Программа должна выводить на экран фамилию и имя разработчика, номер практического занятия и номер варианта.

Вариант 14

$\frac{
	x^{2} - 4x + 4
}{
	(x + 5)^{2} - 49
};$

# knowledge

В данной программе используются следующие Assembler регистры и операции:

| Запись | Тип     | Описание                                                                                                                                    |
| ------ | ------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `EAX`  | Регистр | Основной регистр-аккумулятор. Используется для хранения промежуточных результатов и числителя/знаменателя перед передачей в переменные C++. |
| `EBX`  | Регистр | Регистр общего назначения. Используется для хранения значения `4x` при вычислении числителя.                                                |
| `EDX`  | Регистр | Используется вместе с `EAX` командой `IDIV` для хранения старшей части делимого и остатка от деления.                                       |
| `IMUL` | Команда | Команда знакового умножения целых чисел. Используется для вычисления `x²`, `4x` и `(x + 5)²`.                                               |
| `IDIV` | Команда | Команда знакового целочисленного деления. Делит делимое `EDX:EAX` на указанный операнд. Частное записывается в `EAX`, остаток — в `EDX`.    |
| `MOV`  | Команда | Переносит данные между регистрами и переменными.                                                                                            |
| `ADD`  | Команда | Прибавляет значение исходного операнда к операнду назначения.                                                                               |
| `SUB`  | Команда | Вычитает значение исходного операнда из операнда назначения.                                                                                |
| `CDQ`  | Команда | Расширяет знаковое значение `EAX` в пару регистров `EDX:EAX` перед выполнением `IDIV`.                                                      |
