# Самостоятельная работа №08

## Задание 1

- [ ] Даны два целых числа n и k (n \< k ). Найти сумму всех чисел от n по k включительно.

## Задание 2

- [ ] Даны два целых числа n и k (n \< k*, n \> 0*). Найти произведение всех чисел от n по k включительно.

## Задание 3

- [ ] Дан массив целых чисел Х (положительные и отрицательные). Найти сумму квадратов всех чисел.

## Задание 4

- [ ] Дан массив целых чисел Х (положительные, нулевые и отрицательные). Найти количество отрицательных элементов массива.

## Задание 5

- [ ] Дан массив целых положительных чисел Х. Найти максимальный элемент массива.
