**[СПРАВКА ПО КОМАНДАМ ВЕТВЛЕНИЯ:]{.underline}**

**Ассемблер        Аналогия в PASCAL, BASIC** \
jmp \<метка\>       goto \<метка\> \
Jz \<метка\>         if \<выражение\>=0 then goto \<метка\> \
Jnz \<метка\>       if \<выражение\> 0 then goto \<метка\> \
jc \<метка\>         if \<выражение1\> меньше \<выражения2\> goto
\<метка\> \
jnc \<метка\>       if \<выр.1\> больше или равно  \<выр.2\> goto
\<метка\> \
js \<метка\>         if sgn(\<выр.1\>)=-1 then goto \<метка\> \
jns \<метка\>       if sgn(\<выр.1\>)=1 then goto \<метка\>

**Безусловные переходы**

Безусловный переход --- это переход, который выполняется всегда.
Безусловный переход осуществляется с помощью
команды [JMP](http://asmworld.ru/spravochnik-komand/jmp). У этой команды
один операнд, который может быть непосредственным адресом (меткой),
регистром или ячейкой памяти, содержащей адрес.

Существуют также «дальние» переходы --- между сегментами, однако здесь
мы их рассматривать не будем.

Примеры безусловных переходов:

+------------------------------------------------------------------+
| **jmp** metka *;Переход на метку*                                |
|                                                                  |
| **jmp** **bx** *;Переход по адресу в BX*                         |
|                                                                  |
| **jmp** **word**\[**bx**\] *;Переход по адресу, содержащемуся в  |
| памяти по адресу в BX*                                           |
+------------------------------------------------------------------+

**Условные переходы**

Условный переход осуществляется, если выполняется определённое условие,
заданное флагами процессора (кроме одной команды, которая проверяет CX
на равенство нулю).

Состояние флагов изменяется после выполнения арифметических, логических
и некоторых других команд. Если условие не выполняется, то управление
переходит к следующей команде.

Существует много команд для различных условных переходов. Также для
некоторых команд есть синонимы
(например, [JZ](http://asmworld.ru/spravochnik-komand/jcond) и [JE](http://asmworld.ru/spravochnik-komand/jcond) ---
это одно и то же).

Для наглядности все команды условных переходов приведены в таблице:

  ------------- ------------------------------------- ------------------
   **Команда**            **Переход, если**               **Условие
                                                          перехода**

      JZ/JE                нуль или равно                    ZF=1

     JNZ/JNE            не нуль или не равно                 ZF=0

   JC/JNAE/JB      есть переполнение/не выше и не            CF=1
                             равно/ниже               

   JNC/JAE/JNB   нет переполнения/выше или равно/не          CF=0
                                ниже                  

       JP            число единичных бит чётное              PF=1

       JNP          число единичных бит нечётное             PF=0

       JS                   знак равен 1                     SF=1

       JNS                  знак равен 0                     SF=0

       JO                 есть переполнение                  OF=1

       JNO                нет переполнения                   OF=0

     JA/JNBE           выше/не ниже и не равно           CF=0 и ZF=0

     JNA/JBE           не выше/ниже или равно           CF=1 или ZF=1

     JG/JNLE         больше/не меньше и не равно         ZF=0 и SF=OF

     JGE/JNL         больше или равно/не меньше             SF=OF

     JL/JNGE         меньше/не больше и не равно            SF≠OF

     JLE/JNG         меньше или равно/не больше         ZF=1 или SF≠OF

      JCXZ            содержимое CX равно нулю               CX=0
  ------------- ------------------------------------- ------------------

У всех этих команд один операнд --- имя метки для перехода. Обратите
внимание, что некоторые команды применяются для беззнаковых чисел, а
другие --- для чисел со знаком.

Сравнения «выше» и «ниже» относятся к беззнаковым числам, а «больше» и
«меньше» --- к числам со знаком.

Для беззнаковых чисел признаком переполнения будет флаг CF, а
соответствующими командами
перехода [JC](http://asmworld.ru/spravochnik-komand/jcond) и [JNC](http://asmworld.ru/spravochnik-komand/jcond).
Для чисел со знаком о переполнении можно судить по состоянию флага OF,
поэтому им соответствуют команды
перехода [JO](http://asmworld.ru/spravochnik-komand/jcond) и [JNO](http://asmworld.ru/spravochnik-komand/jcond).
Команды переходов не изменяют значения флагов.

**Команды CMP и TEST**

Часто для формирования условий переходов используются
команды [CMP](http://asmworld.ru/spravochnik-komand/cmp) и [TEST](http://asmworld.ru/spravochnik-komand/test).
Команда [CMP](http://asmworld.ru/spravochnik-komand/cmp) предназначена
для сравнения чисел.

Она выполняется аналогично
команде [SUB](http://asmworld.ru/spravochnik-komand/cmp): из первого
операнда вычитается второй, но результат не записывается на место
первого операнда, изменяются только значения флагов.

> Например:

+------------------------------------------------------------------+
| **cmp** **al**,5 *;Сравнение AL и 5*                             |
|                                                                  |
| **jl** c1 *;Переход, если AL \< 5 (числа со знаком)*             |
+------------------------------------------------------------------+
| **cmp** **al**,5 *;Сравнение AL и 5*                             |
|                                                                  |
| **jb** c1 *;Переход, если AL \< 5 (числа без знака)*             |
+------------------------------------------------------------------+

Команда [TEST](http://asmworld.ru/spravochnik-komand/test) работает
аналогично команде [AND](http://asmworld.ru/spravochnik-komand/and), но
также результат не сохраняется, изменяются только флаги.

> С помощью этой команды можно проверить состояние различных битов
> операнда. Например:

+------------------------------------------------------------------+
| **test** **bl**,00000100b *;Проверить состояние 2-го бита BL*    |
|                                                                  |
| **jz** c2 *;Переход, если 2-й бит равен 0*                       |
+------------------------------------------------------------------+
