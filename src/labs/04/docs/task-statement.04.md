# Лабораторная работа №04

ЛАБОРАТОРНАЯ РАБОТА № 4 (4 часа)

**Цель:** Изучение работы логических команд.

Реализовать вычисление указанных формул в виде ассемблерных вставок в
текст программы на С++. Вычисления осуществлять в целых числах **типа
integer**.

Объявление необходимых переменных, ввод данных и вывод результатов на
экран реализовать на С++. Для проверки правильности вычисления
ассемблерной вставки реализовать вычисления на С++ с выводом результатов
на экран.

Программа должна выводить на экран фамилию разработчика, номер
лабораторной работы и номер варианта.

**Среда программирования: Visual Studio.**

**Язык программирования: С++, Assembler.**

Вариант **0**

a, если x \> 0;

y = a + b, если x = 0;

b, если x \< 0;
