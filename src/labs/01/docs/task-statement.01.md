**Часть 1.**

**Цель:** Изучение работы команд пересылки и арифметической команды
процессора **add** (сложение).

Реализовать вычисление формулы **c = a + b** в виде ассемблерных вставок
в текст программы на С++. Вычисления осуществлять в целых числах типа
**int** (использовать регистры процессора).

Объявление необходимых переменных, ввод данных и вывод результатов на
экран реализовать на С++.

**Среда программирования:**

**Visual Studio. Консольное приложение С++. Конфигурация: x86, win32**

**Язык программирования**: С++, Assembler.

```cpp
#include <iostream> // подключаем библиотеку с функциями ввода-вывода,

// это команды printf и system

int main()// обычный код на C++

{

int a = 1; // объявляем переменную a и кладем туда значение 1
int b = 2; // объявляем переменную a и кладем туда значение 2
int c; // объявляем переменную c, но не инициализируем ее

// далее идет ассемблерная вставка (два подчеркивания и следом слово (asm)

__asm
{ // начало ассемблерной вставки
mov eax, a // загружаем значение переменной a в регистр EAX
add eax, b // складываем a с b, записывая результат в EAX
mov c, eax // загружаем значение EAX в переменную c
} // конец ассемблерной вставки

// далее следует снова обычный код на C++

// выводим содержимое c на экран с помощью функции printf

printf("a + b = %x + %x = %xn", a, b, c);

system("pause");

return 0;

}
```
